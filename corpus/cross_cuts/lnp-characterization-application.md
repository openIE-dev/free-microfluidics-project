## Refeyn TwoMP / SamuxMP LNP Characterization Application (2022-09)

- **id**: `refeyn-twomp-lnp-application`
- **corpus**: private
- **device class**: lab-on-chip
- **creator**: Refeyn Ltd.
- **disclosure**: Refeyn LNP application note 2022-09; SamuxMP product launch 2024
- **ip status**: patented
- **prior art notes**: Extends the existing refeyn-twomp-mass-photometry entry by disclosing the LNP-specific application: using interferometric-scattering single-particle mass photometry to quantify per-LNP mRNA payload heterogeneity (full / empty / partial LNP populations), a metric that drives mRNA-LNP CMC release decisions and competes with cryo-EM and SEC-MALS.
