## Mimaki JFX600-2531 UV-LED Flatbed Inkjet (2022)

- **id**: `mimaki-jfx600-2531-uv-flatbed`
- **corpus**: private
- **device class**: inkjet-printhead
- **creator**: Mimaki Engineering Co., Ltd.
- **disclosure**: Mimaki JFX600-2531 launch FESPA 2022; Mimaki UV flatbed datasheet 2022
- **ip status**: patented
- **prior art notes**: Industrial UV flatbed inkjet for rigid substrates. Architectural primitives include the staggered piezo printhead array with on-the-fly UV-LED cure trailing each pass, MAPS variable-pass-pattern algorithm reducing visible banding, and a multi-channel ink stack including primer, white, clear, and light cyan/magenta for extended gamut. Anticipates: industrial UV flatbed inkjet using staggered printhead array + trailing UV-LED cure + multi-channel pre-/post-treatment ink stack on a vacuum-bed transport.
