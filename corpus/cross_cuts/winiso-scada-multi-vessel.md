## HEL Hexa Vessel Parallel Bioreactor System (2014)

- **id**: `hel-hexa-vessel-parallel-bioreactor`
- **corpus**: private
- **device class**: flow-controller
- **creator**: HEL Group (London, UK)
- **disclosure**: HEL Group Hexa parallel reactor product brochure 2014-2018; HEL FlexBio bioreactor documentation 2017
- **ip status**: patented
- **prior art notes**: Discloses the HEL Hexa Vessel six-position parallel reactor system, configurable as either chemistry process-development reactor or parallel bioreactor. The architecture provides independent per-vessel control of temperature, agitation, gas-flow, and reagent dosing across six 50-1000 mL vessels. Anticipates: (a) six-vessel parallel reactor architecture spanning chemistry and biology applications on the same hardware; (b) WinISO software stack as a multi-vessel reactor SCADA precursor; (c) the modular-vessel-slot architecture enabling vessel-volume mixing within a single bank. Cite against later patents claiming six-vessel parallel reactors with bivalent chemistry/biology configuration.
