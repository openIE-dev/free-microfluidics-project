## ThermoFisher Convergence Forensic Allele Calling and Casework Software 3.4 (2019)

- **id**: `thermofisher-convergence-dx-3-4`
- **corpus**: private
- **device class**: other
- **creator**: ThermoFisher Scientific
- **disclosure**: ThermoFisher Scientific Convergence software documentation 2019; product launch 2019.
- **ip status**: patented
- **prior art notes**: Software-only entry covering the data-analysis side of the Rapid DNA workflow. While not microfluidic itself, it is the canonical end-to-end software for the 3500 + RapidHIT + Spectrum cartridge ecosystem and defines the data-flow from cartridge readout to CODIS database. Discloses: unified data-analysis workflow accepting raw CE traces from 3500/3500xL, RapidHIT 200/ID, and (with translation) ANDE/Spectrum data; automated allele calling with bin/peak/stutter/artifact filtering; CODIS-compliant XML export. Anticipates: unified data-analysis software spanning multiple cartridge form factors; the architectural pattern of cartridge-to-CODIS data flow with audit-trail integrity; specifically the cross-cartridge data normalization needed to use multiple Rapid DNA platforms in a single forensic lab. Flagged as software / non-microfluidic but adjacent for completeness.
