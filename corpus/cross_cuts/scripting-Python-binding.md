## Micro-Manager 2.0 (μManager 2.0) (2014)

- **id**: `micromanager-v2-acquisition-platform`
- **corpus**: open
- **device class**: other
- **creator**: Nico Stuurman, Arthur Edelstein, Hazen Babcock and contributors (UCSF, Vale lab)
- **disclosure**: Edelstein AD, Tsuchida MA, Amodaj N, Pinkard H, Vale RD, Stuurman N. Advanced methods of microscope control using μManager software. Journal of Biological Methods 1(2): e10 (2014). doi:10.14440/jbm.2014.36 ; v2.0 release notes https://micro-manager.org/Version_2.0
- **ip status**: open-copyleft
- **prior art notes**: Wave-2 strengthening of the wave-1 micromanager-imaging entry by pinning the v2.0 disclosure with primary citation to JBM. Element-by-element: (1) C++ MMCore with hardware-abstraction interface; (2) device adapters for stages, cameras, illuminators, filter wheels; (3) multi-dimensional acquisition engine; (4) Pycro-Manager Python binding (subsequent disclosure 2021). Anticipates: claims directed to plug-in-style microscope-control software with vendor-neutral device abstractions, and to the integration of Python scripting with C++ acquisition cores for closed-loop microscopy on microfluidic chips.
