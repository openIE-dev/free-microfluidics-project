## Microsoft Project Natick + Two-Phase Immersion Cooling Subsea Data Center (2018-06-05)

- **id**: `microsoft-natick-twophase-cooling`
- **corpus**: private
- **device class**: cooling-substrate
- **creator**: Microsoft Research + Naval Group
- **disclosure**: Microsoft Project Natick technical report 2018-06; Cutress, AnandTech 2018-06-06; Microsoft Project Natick paper Cutress 2020.
- **ip status**: patented
- **prior art notes**: Microsoft Project Natick demonstrated a sealed-Ti-cylinder data center with N2-internal atmosphere, server cold plates carrying heat to a heat exchanger that dumps into surrounding seawater via passive convection. Microfluidic-relevant content: per-server cold plates with microchannel-or-skived structure; closed loop carrying heat to the cylinder skin; seawater external convection as the ultimate heat sink. Discloses: hermetically-sealed dry-N2 server enclosure (eliminating O2-driven corrosion); per-server cold-plate-based liquid cooling; passive external seawater heat exchange; the architectural pattern of a sealed underwater data center using ocean as the heat sink. Anticipates: hermetic dry-atmosphere data center pods; per-server cold-plate liquid cooling with passive ambient heat sinks; the architectural-economic argument that hermetic + cold-plate cooling enables 8x reliability gain at scale.
